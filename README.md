# 에버소울 유저 리뷰 분석 — 서브컬처 신작 마케팅 교훈 도출

카카오게임즈 서브컬처 수집형 RPG 마케팅PM 지원 포트폴리오

## 개요
2026년 6월 종료한 에버소울의 유저 리뷰 4,000건(게임별 2,000건)을 수집, 분석해
차기 서브컬처 수집형 RPG의 장기 흥행을 위한 마케팅 교훈을 도출한 프로젝트입니다.

## 전제
종료의 근본 원인은 개발사 나인아크의 경영 위기로 인한 콘텐츠 공백이며,
본 분석은 원인 규명이 아니라 마케팅이 통제 가능한 영역으로 범위를 한정합니다.

## 사용 기술
Python, google-play-scraper, KoNLPy, 감성분석, 데이터 시각화

## 파일
- kakaogames01.ipynb : 수집부터 분석까지 전체 코드
- eversoul_reviews.csv : 에버소울 리뷰 (2026년 7월 구글플레이 수집)
- bluearchive_reviews.csv : 블루아카이브 리뷰 (2026년 7월 구글플레이 수집)

## 한계
종료 직전 작별 리뷰 비중이 높아 표본이 5점에 편향되어 있으며,
리뷰 수는 활성 유저의 간접 지표로 해석했습니다.
